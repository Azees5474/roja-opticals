## 💡 Pro Tips for Best Experience

### Browser Settings
1. **Enable Hardware Acceleration**: 
   - Chrome: `chrome://settings` → Advanced → System
   - Edge: `edge://settings` → System and performance

2. **Enable Smooth Scrolling**:
   - Settings → Appearance → Smooth scrolling

3. **High Refresh Rate Monitor**:
   - Set to 120Hz or higher for smoothest experience

### Window Size
- **Best viewed**: Full screen or maximized window
- **Minimum**: 1280x720 for all animations

### Performance
- **Close other tabs** for best frame rate
- **Disable extensions** if experiencing lag
- **Use Chrome/Edge** for best animation support

## 🎬 Animation Names Reference

All animations defined in CSS:

1. `fadeIn` - Opacity transition
2. `fadeInUp` - Fade + move up
3. `slideIn` - Slide from left
4. `slideInLeft` - Slide from left (login)
5. `float` - Up and down movement
6. `pulse` - Opacity pulse
7. `bounce` - Up and down bounce
8. `scaleIn` - Scale from 0.9 to 1
9. `shimmer` - Light sweep effect
10. `gradientShift` - Background animation
11. `spin` - Rotate 360°
12. `tableEnter` - Table rows entry
13. `overlayEnter` - Modal backdrop
14. `modalEnter` - Modal entry
15. `dropIn` - Dropdown entry
